Everything a notes app should do, done properly.

No clutter, no setup. Each feature is there because you'll use it every day.

Editor

Write the way you think.

Type / for headings, checklists, quotes, code and dividers. Select text and a bubble offers bold, italic, highlight and links. Every edit autosaves, with an explicit Save when you want to be sure.

  • ✓ Slash commands and a floating formatting bubble
  • ✓ Checklists that tick off right on the card
  • ✓ Keyboard: ⌘S to save, Esc to close, ⌘K to search
Organise

Colours, labels, pins and drag.

Ten Keep colours, labels you create inline, pins that float to the top, and a wall you can rearrange by dragging with a mouse, a finger or the keyboard. The order is yours and it's saved.

  • ✓ Labels in the sidebar filter the wall with one click
  • ✓ Drop a note into the pinned row to pin it
  • ✓ Grid or list view, remembered per device
Peace of mind

Nothing gets lost.

Archive what's done, trash what's not, and undo either from a toast. The trash keeps notes for seven days. Search covers titles, text and label names as you type.

  • ✓ Undo on archive, trash and restore
  • ✓ Trashed notes open read-only until restored
  • ✓ Private by default: your notes are only yours
Everywhere

Looks right on every screen.

A two-column wall and a slide-in drawer on phones, a full sidebar on desktops, and a dark theme that follows your system.

API

Built on an open API.

Everything the app does goes through a documented REST API with cookie sessions. Explore it live in Swagger, or read it in ReDoc.

Open Swagger UI ReDoc OpenAPI JSON 
# sign in (sets the session cookie)
curl -c jar -X POST https://draftify-gamma.vercel.app/api/auth/login \
  -H 'content-type: application/json' \
  -d '{"email":"you@example.com","password":"your-password"}'

# create a note
curl -b jar -X POST https://draftify-gamma.vercel.app/api/notes \
  -H 'content-type: application/json' \
  -d '{"title":"Hello","content":"<p>from the API</p>","color":"teal"}'

# reorder in one call
curl -b jar -X POST https://draftify-gamma.vercel.app/api/notes/reorder \
  -H 'content-type: application/json' -d '{"ids":[12,7,3]}'

Under the hood

Small, boring, well-tested choices.

Frontend

React 19, TanStack Query with optimistic updates, TipTap editor, dnd-kit, Tailwind v4. Vitest + Testing Library.

Backend

FastAPI + SQLModel, Argon2 passwords, JWT cookie sessions, per-user scoping in the store layer. 46 pytest cases over two stores.

Data

Postgres on Supabase with self-applying migrations, or an in-memory store for zero-setup local runs.

Hosting

Vercel: static frontend plus a Python function pinned next to the database, one pooled connection per warm instance.
